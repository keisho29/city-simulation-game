# 2D都市シミュレーションゲーム 仕様書

**バージョン：Ver.0.1**\
**開始年代：1700年**\
**プラットフォーム：Webブラウザ**

---

## 1. ゲーム概要

地球をモデルにした架空世界を舞台とする、2D都市シミュレーションゲーム。

プレイヤーは建物や道路などを配置して街の基盤を作る。

一方、住民はプレイヤーが直接操作せず、自律的に入居・就職・出勤・勤務・帰宅などの行動を行う。

プレイヤーが街のすべてを管理するのではなく、

**「プレイヤーが街を作り、住民がその街で自律的に生活する」**

ことを基本コンセプトとする。

ゲームに明確なクリア条件やゲームオーバーは設けない。

---

## 2. 世界観

### 2.1 舞台

現実の地球をモデルとした架空世界。

実際の地域について、以下のような特徴を参考にする。

- 地理
- 気候
- 自然環境
- 地域特性

ただし、現実世界を完全再現することは目的としない。

都市、人口、経済、交通網などはプレイヤーの行動によって現実とは異なる発展をする。

例：

- 北海道モデル地域 → 寒冷
- 沖縄モデル地域 → 温暖
- 東京モデル地域 → 都市発展のポテンシャルが高い

地域特性は「できる・できない」を決定するものではなく、発展のしやすさなどへの補正として扱う予定。

### 2.2 開始地域

ゲーム開始時は、**東京をモデルとした架空地域**のみ操作可能。

Ver.0.1では他地域の実装は行わない。

将来的には交通インフラを接続することで、

東京モデル地域 → 関東 → 日本 → アジア → 世界

と活動範囲を拡大できるようにする。

---

## 3. 時代

### 3.1 開始年代

**1700年から開始する。**

ただし、1700年当時の東京を完全再現する歴史ゲームとはしない。

1700年ごろの建築・交通・技術・生活水準・産業などを参考にした架空世界とする。

プレイヤーの行動によって現実とは異なる歴史を形成できる。

### 3.2 将来の時代進行

長期的には、

1700年代 → 1800年代 → 1900年代 → 2000年代 → 現代 → 架空の未来 → 継続

という発展を想定する。

現代以降もゲーム終了とはせず、架空技術などを追加して発展を継続できる設計を目指す。

※Ver.0.1では高度な時代・技術解放システムは実装しない。

---

## 4. ゲーム内時間

### 4.1 通常速度

通常速度（×1）では、**現実時間60分 = ゲーム内1か月**とする。

したがって、

- 1か月 = 60分
- 6か月 = 6時間
- 1年 = 12時間

時間設定は将来的なバランス調整を考慮し、固定値を各処理へ直接記述せず、設定値として変更可能な設計とする。

### 4.2 時間速度

モード 1か月の現実時間

---

一時停止 進行しない
×1 60分
×2 30分
×5 12分

住民の行動などはゲーム内時間を基準として処理する。

### 4.3 オフライン時

ゲームを閉じている間はゲーム内時間を進めない。

再度ゲームを開いた場合は、保存されたゲーム内時刻から再開する。

オフライン進行はVer.0.1では実装しない。

---

## 5. マップ

### 5.1 マップ形式

**正方形グリッド方式**を採用する。

初期サイズ：**50 × 50マス**（合計2,500マス）。

### 5.2 マス

各マスには状態を持たせる。

- 空き地
- 道路
- 住宅
- 農地
- 商店
- 工房

原則として1マスに1つの建築物または道路を配置する。

将来的に複数マスを使用する大型建築物への拡張を想定する。

---

## 6. プレイヤー操作

プレイヤーは都市そのものを直接管理する。

主な操作：

- 建物を選択
- マップ上へ配置
- 道路を配置
- ゲーム速度変更
- 都市情報確認
- 住民情報確認

住民個人を直接操作する機能は設けない。

---

## 7. 建築

### 7.1 基本ルール

建築物の設置位置はプレイヤーが決定する。

将来的には、

1.  プレイヤーが自主的に建設
2.  住民からの要望を受けて建設

の両方を可能にする。

住民からの要望に従うことは強制ではない。

### 7.2 Ver.0.1の建築物

#### 木造住宅

住民の居住場所。住民は空きのある住宅へ自律的に入居する。

#### 農地

住民の勤務先。雇用を発生させる。

#### 商店

商業活動および勤務先。Ver.0.1では買い物AIなどは実装せず、主に雇用・税収に使用する。

#### 工房

生産活動および勤務先。雇用を発生させる。

#### 道路

建物同士を接続し、住民の移動経路として利用する。

### 7.3 将来追加予定

Ver.0.1では以下を実装しない。

- 学校
- 病院
- 公園
- 駅
- 鉄道
- 港
- 空港
- 工場
- 高層住宅
- オフィス
- 発電施設
- その他時代に応じた施設

---

## 8. 建物の進化

建物の配置はプレイヤーが行う。その後の建物の発展・進化はゲーム側で自動的に行う構想とする。

例：木造住宅 → 集合住宅 → マンション → 高層住宅

進化条件として将来的に、入居率・幸福度・交通・周辺施設・人口・時代・技術などを使用する。

**Ver.0.1では本格的な建物進化システムは実装対象外とする。**

---

## 9. 住民

### 9.1 基本思想

住民はプレイヤーが直接操作しない。

ゲーム側のロジックによって自律的に行動する。

Ver.0.1では生成AIを使用せず、ルールベースのゲームAIとして実装する。

### 9.2 住民データ

- ID
- 名前
- 年齢
- 自宅
- 勤務先
- 幸福度
- 現在状態

### 9.3 住民状態

- `HOME`
- `MOVING_TO_WORK`
- `WORKING`
- `MOVING_TO_HOME`

---

## 10. 住民AI

Ver.0.1では以下の行動のみ実装する。

### 入居

空き住宅を探し、自律的に入居する。

### 就職

空き求人のある農地・商店・工房などから勤務先を決定する。

### 出勤

ゲーム内の朝になると、自宅から勤務先へ移動する。

### 勤務

勤務時間中は勤務先に滞在する。

### 帰宅

勤務終了時間になると、自宅へ戻る。

### 10.1 将来追加予定の住民行動

Ver.0.1では以下を実装しない。

- 買い物
- 食事
- 学校
- 転職
- 引越し
- 結婚
- 出産
- 家族
- 老化
- 病気
- 死亡
- 趣味
- 友人関係
- 犯罪
- 詳細な性格

---

## 11. 幸福度

住民ごとに幸福度を保持する。

Ver.0.1では簡易的な計算とする。

例：

- 仕事がある → 上昇
- 仕事がない → 低下
- 通勤距離が短い → 上昇
- 通勤距離が長い → 低下

将来的には医療・教育・治安・環境・公園・所得・家族・交通などを追加する。

- 現在年月

- 資金

## 15. セーブ

保存対象：

- ゲーム内年月

## 18. Web公開

ゲームはWebブラウザ上で動作する。

URLへアクセス → ゲーム読み込み → そのままプレイ、という形を目標とする。

インストールやユーザー登録はVer.0.1では不要。

## 19. 将来の地域解放

Ver.0.1対象外。

将来的には新しい地域へ到達可能な交通インフラを完成させることで地域を解放する。

例：

- 鉄道
- 新幹線
- 船
- 航空

単純な人口レベルによる自動解放ではなく、**「交通網を自分で構築した結果、世界が広がる」**ことを基本思想とする。

## 21. Ver.0.1 開発順序

### Phase 1：プロジェクト

TypeScript + Phaser +
Viteのプロジェクトを作成し、ブラウザ上にゲーム画面を表示する。

### Phase 2：マップ

50×50の正方形グリッドマップを表示する。

### Phase 3：建築

最初は木造住宅のみ実装する。建築メニューから住宅を選択し、マップをクリックすると配置できるようにする。

### Phase 4：道路・その他建築

道路、農地、商店、工房を追加する。

### Phase 5：ゲーム内時間

1700年1月から開始。一時停止 / ×1 / ×2 / ×5を実装する。

### Phase 6：住民1人

住民を1人生成し、住宅へ入居させる。

### Phase 7：就職

農地・商店・工房から勤務先を決定する。

### Phase 8：通勤

朝は自宅 → 勤務先、夕方は勤務先 → 自宅という移動を実装する。

### Phase 9：住民増加

1人 → 10人 → 20人と増加させる。

### Phase 10：都市情報

人口、雇用状況、幸福度、資金を表示する。

### Phase 11：セーブ

localStorageへゲーム状態を保存し、ブラウザを閉じても前回状態から再開できるようにする。

## 22. Ver.0.1 完成条件

以下がすべて動作すればVer.0.1完成とする。

- 1700年の東京モデル地域を50×50グリッドで表示できる
- 道路、木造住宅、農地、商店、工房を配置できる
- 住民が住宅へ入居する
- 住民が勤務先を決定する
- 朝に出勤する
- 勤務する
- 夕方に帰宅する
- 一時停止 / ×1 / ×2 / ×5で時間を操作できる
- 人口、雇用状況、平均幸福度、資金を確認できる
- ゲーム状態を保存・再開できる

## 23. 開発原則

Ver.0.1では完成を最優先する。

新しいアイデアが出ても、Ver.0.1完成に不要な機能は原則として追加せず、将来仕様として記録する。

特に以下を最初から実装しない。

- 世界全体
- 鉄道
- 海外
- 家族
- 結婚
- 出産
- 高度な経済
- 高度な住民AI
- 美麗なグラフィック

まず、**「建物を置くと、住民がそこで生活し始める」**というゲームの最小コアを完成させる。
